# Rebrew workflow and stores

The target is `main`, namespace `MAIN`, architecture `x86_16`, format `ne`, with the `delphi-1.0` compiler profile. [Build](build.md) owns setup; [native format](native-format.md) owns address interpretation.

## Durable owners

| State | Owner |
| --- | --- |
| Target paths, toolchain and switches | [rebrew-project.toml](../rebrew-project.toml) |
| Native procedure boundaries | [function_structure.json](../src/main/function_structure.json) and reviewed [extent merges](../src/main/function_merges.toml) |
| Function identities, notes and verification fields | [rebrew-functions.toml](../rebrew-functions.toml), format 3 |
| Data ownership and verification fields | [rebrew-data.toml](../rebrew-data.toml), format 2 |
| NE segment facts | [segments.json](../layout/main/segments.json) |
| Source bodies | [gen_tree.py](../tools/gen_tree.py), with tracked Pascal snapshots |
| Form layouts | [layouts.json](../src/main/forms/layouts.json), with generated DFM snapshots |
| Progress receipt | [status.json](../status.json), generated by [gen_status.py](../tools/gen_status.py) |

Do not hand-edit managed TOML state or fabricate match statuses from documentation. [gen_rebrew_functions.py](../tools/gen_rebrew_functions.py) uses the locked Rebrew writer to refresh source identities and notes; it assigns no verification verdicts.

## Day-to-day commands

```sh
uv run --frozen rebrew status --json
uv run --frozen rebrew todo --json
make metadata
make forms
make docs-check
```

Read the installed command's `--help` before combining flags. The [packaged workflow skill](../.agents/skills/rebrew-workflow/SKILL.md) and [tool selection](../.agents/skills/rebrew-workflow/references/tool-selection.md) describe public CLI/API ownership.

This target compiles a complete Delphi project. Do not assume the C/COFF per-function skeleton and linking recipes apply to it. `rebrew build layout` is currently PE-only and reports no PE signature for this executable; the [NE layout notes](../layout/main/README.md) record the appropriate convention.

## Edits and locking

Edit generator-owned bodies in `gen_tree.py`, then regenerate the source and refresh metadata. Address comments reference managed bindings; an unresolved helper receives no invented identity. A binding rename must be reviewed in the managed store before a generator can annotate its new definition.

Use [regen_build_compare.py](../tools/regen_build_compare.py) for the serialized native cycle. Metadata locks protect store writes; they do not make concurrent source edits safe. Keep one build/source writer at a time, and put bounded experiments under ignored `.scratch/`.

`make clean` preserves source and evidence. See [workflow traps](workflow-traps.md) before reviving old worker scripts or cached probes.
